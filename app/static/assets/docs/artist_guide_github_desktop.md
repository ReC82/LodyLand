# 🎨 Guide artiste – LodyLand (version simple avec GitHub Desktop)

## Objectif

Ajouter des fichiers graphiques au projet sans toucher au code.

## Outils à installer

* GitHub Desktop
* VSCode ou un explorateur de fichiers classique
* Un logiciel de dessin/export PNG/SVG

---

## 1. Se connecter à GitHub Desktop

* Ouvrir GitHub Desktop
* Se connecter avec son compte GitHub

---

## 2. Récupérer le projet

* Cliquer sur **File > Clone repository**
* Choisir le repo **LodyLand**
* Choisir un dossier sur le PC
* Cliquer sur **Clone**

---

## 3. Créer une branche de travail

Pour un premier travail sur le logo :

* Cliquer sur le nom de la branche actuelle
* Cliquer sur **New Branch**
* Nom conseillé :

```text
artist/logo-v1
```

* Cliquer sur **Create Branch**

---

## 4. Ajouter les fichiers

Déposer les fichiers dans le bon dossier du projet :

```text
assets/ui/logo/
```

Exemples :

* `logo_v1.png`
* `logo_v1.svg`

---

## 5. Vérifier les changements

Retourner dans GitHub Desktop.

Les fichiers modifiés ou ajoutés apparaîtront dans la liste.

---

## 6. Faire le commit

En bas à gauche :

### Summary

```text
Ajout logo v1
```

### Description

```text
Première proposition de logo pour LodyLand.
```

Puis cliquer sur :

**Commit to artist/logo-v1**

---

## 7. Envoyer sur GitHub

Cliquer sur :

**Push origin**

---

## 8. Créer une Pull Request

Cliquer sur :

**Create Pull Request**

Titre conseillé :

```text
Logo v1
```

Description conseillée :

```text
Ajout de la première version du logo dans assets/ui/logo/.
Formats fournis : PNG et SVG.
```

---

## Règles importantes

* Ne jamais travailler sur `main`
* Travailler uniquement dans les dossiers `assets/...`
* Faire une branche par tâche
* Faire une Pull Request quand le travail est prêt

---

## En cas de doute

Ne pas forcer, ne pas supprimer des fichiers au hasard, et demander avant de continuer.
