# 🎨 LodyLand – Guide rapide pour les artistes

## 🎯 Objectif

Ajouter des éléments graphiques (logo, icônes, UI…) dans le projet.

---

## 📁 Où mettre les fichiers

Respecter cette structure :

```text
assets/
  ui/
    logo/
  icons/
  tiles/
```

Exemple pour le logo :

```text
assets/ui/logo/logo_v1.png
assets/ui/logo/logo_v1.svg
```

---

## 🌿 Branches

Toujours créer une branche pour chaque tâche :

```text
artist/logo-v1
artist/icons-tools-v1
artist/ui-buttons-v1
```

❌ Ne jamais travailler sur `main`

---

## 📝 Nommage des fichiers

Utiliser des noms simples et clairs :

```text
logo_v1.png
icon_axe.png
button_play.png
```

---

## 📦 Formats attendus

* PNG (obligatoire)
* SVG (si possible)
* Fond transparent recommandé

---

## 🔄 Workflow

1. Créer une branche
2. Ajouter les fichiers dans `/assets`
3. Commit + Push
4. Créer une Pull Request

---

## 📬 Pull Request (PR)

Titre :

```text
Logo v1
```

Description :

```text
Ajout du logo v1 dans assets/ui/logo/
Formats : PNG + SVG
```

---

## ⚠️ Règles importantes

* Ne pas modifier le code
* Ne pas supprimer des fichiers existants
* Ne travailler que dans `/assets`
* 1 tâche = 1 branche = 1 PR

---

## ❓ En cas de doute

Toujours demander avant de faire une modification importante.
